# Murshed Ahmed — Personal Portfolio Website

A modern, high-performance interactive personal portfolio website showcasing academic qualifications, software engineering projects, technical skillsets, and achievements.

Featuring a smooth 60fps/120fps hardware-accelerated scroll-scrubbed canvas background animation, glassmorphic UI cards, and responsive design.

---

## 🚀 Live Demo

- **Live Website**: [https://portfolio-website-murshed3.vercel.app](https://portfolio-website-murshed3.vercel.app)
- **Local Development**: `http://localhost:3000/`


---

## 🛠️ Tech Stack

- **Frontend**: HTML5 Semantic Markup, Vanilla CSS3 (Custom Design System, Glassmorphism, CSS Variables, Flexbox/Grid), Vanilla ES6+ JavaScript
- **Graphics & Animation**: HTML5 `<canvas>` 2D Context, dynamic multi-worker frame preloader, requestAnimationFrame loop with Linear Interpolation (LERP)
- **Local Dev Server**: Zero-dependency Node.js HTTP static server with immutable caching headers
- **Deployment**: Vercel (Edge Network CDN with custom asset cache headers)

## 💻 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Murshed1603/portfolio-website.git
   cd portfolio-website
   ```

2. **Start the local server**:
   ```bash
   npm run dev
   ```
   or
   ```bash
   node server.js
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000/`

---

## 🌐 Deploying to Vercel

1. Push your repository to GitHub.
2. Sign in to [Vercel](https://vercel.com/) with your GitHub account.
3. Click **Add New...** → **Project**.
4. Import your portfolio repository.
5. In **Framework Preset**, select **Other** (Root directory: `./`).
6. Click **Deploy**. Vercel will deploy your site globally in seconds!
